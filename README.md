# Web Development Projects..

A collection of two full web applications built to practise front-end and back-end development: an **E-commerce website** and a **Job Portal**.

## Projects

### 1. E-commerce Website
An online shopping website where users can browse products, add items to a cart, and place orders.

- **Folder:** [`E-commerce`](./E-commerce)
- **Tech:** HTML, CSS, JavaScript *(add React / Node.js / MongoDB etc. if used)*

**Features**
- Product listing with images, prices, and details
- Search and category filters
- Add to cart, update quantity, remove items
- Checkout page with order summary
- User login and registration
- Responsive design for mobile and desktop

### 2. Job Portal
A job search platform that connects job seekers with employers.

- **Folder:** [`Job_portal`](./Job_portal)
- **Tech:** HTML, CSS, JavaScript *(add backend / database if used)*

**Features**
- Browse and search job listings
- Filter by role, location, and job type
- Job seeker registration and login
- Apply for jobs online
- Employer dashboard to post and manage jobs
- Responsive design for mobile and desktop
